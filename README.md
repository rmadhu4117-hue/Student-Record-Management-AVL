Student Record Management Using AVL Tree

Project Description

Student Record Management Using AVL Tree is a Java-based Advanced Data Structures project.

The project stores student records using an AVL Tree. An AVL Tree is a self-balancing Binary Search Tree that maintains balance after insertion and deletion.

Features

- Add student record
- Search student by ID
- Delete student record
- Display all student records
- Automatic AVL Tree balancing
- Left and right rotations
- Inorder traversal

Technologies Used

- Java
- AVL Tree
- Object-Oriented Programming
- Git
- GitHub

Student Details Stored

Each student record contains:

- Student ID
- Student Name
- Marks

Data Structure

The project uses an AVL Tree.

The Student ID is used as the key.

             103
            /   \
          101    105

AVL Tree

An AVL Tree is a self-balancing Binary Search Tree.

For every node:

Balance Factor = Height of Left Subtree - Height of Right Subtree

The balance factor must be:

-1, 0, or +1

If the tree becomes unbalanced, rotations are performed.

Rotations Used

1. Left Rotation
2. Right Rotation
3. Left-Right Rotation
4. Right-Left Rotation

Operations

Operation| Average/Worst Time
Insert| O(log n)
Search| O(log n)
Delete| O(log n)
Display| O(n)
